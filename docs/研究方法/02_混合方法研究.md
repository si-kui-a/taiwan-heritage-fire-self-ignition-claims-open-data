# 混合方法研究（Mixed Methods Research）

建立：2026-09-30｜層次：方法論｜常用於：需要同時回答「有多少」與「為什麼、怎麼發生」的研究

**一句話**：在同一個研究中，有計畫地結合質性與量化資料或分析，讓兩者回答彼此回答不了的部分。

## 主要文獻

| 文獻 | 貢獻 |
|---|---|
| Small（M21，2011） | 回顧社會學混合方法研究的發展，區分「混合資料蒐集」與「混合資料分析」，並討論結合兩者的動機與設計 |
| Lieberman（M20，2005） | 巢狀分析：以大樣本分析引導個案選擇，是混合方法的一種具體設計（見[巢狀分析](03_巢狀分析.md)） |

## 核心概念

| 概念 | 說明 |
|---|---|
| 主從關係 | 常見記法：大寫表示主要方法，小寫表示輔助，例如 QUAL + quan（質性為主）或 QUAN + qual |
| 時序 | 同時進行（concurrent）或先後進行（sequential）：先後進行時，前一階段的結果決定下一階段做什麼 |
| 結合的目的 | 互補（各回答不同部分）、確認（兩種資料是否得到一致結論）、發展（一種方法的結果用來設計另一種） |
| 整合點 | 兩種資料在哪裡相遇：設計階段、分析階段（例如把質性編碼轉成次數）或詮釋階段 |

## 常見設計

| 設計 | 流程 | 適合 |
|---|---|---|
| 平行並進 | 質性與量化同時蒐集，分析後比較 | 從不同角度確認同一問題 |
| 解釋性循序 | 先量化找出模式，再以質性解釋模式或例外 | 量化結果需要機制說明 |
| 探索性循序 | 先質性界定概念與類別，再以量化測量分布 | 概念尚未成熟、沒有現成量表 |
| 巢狀 | 在一個主要設計中嵌入另一種方法，例如大樣本中選個案深入 | 樣本有限、需要深入少數個案 |

## 操作步驟

1. 先寫清楚每個研究問題需要哪一種證據，再決定哪個方法為主。
2. 決定時序：哪一階段的結果會影響下一階段，影響的規則事先寫定。
3. 分別依各自的標準確保品質：量化看信度、效度與推論範圍；質性看可信度（見[質性研究的可信度](08_質性研究的可信度.md)）。
4. 在報告中說明兩種結果如何整合，一致與不一致之處都呈現。

## 品質判準

- 每個方法都有明確任務，而不是為了看起來完整而加入。
- 樣本小的時候，量化部分以描述、效果量與區間為主，不勉強做檢定（見[描述統計、效果量與精確信賴區間](13_描述統計效果量與精確信賴區間.md)）。
- 兩種結果矛盾時，報告矛盾並討論原因，不挑選其中一種。

## 常見誤用

| 誤用 | 問題 |
|---|---|
| 質性只當量化結果的「例子」 | 失去質性分析發現新類別與機制的功能 |
| 把少數個案的次數做顯著性檢定 | 樣本不支持推論，結論不穩定 |
| 兩部分各做各的，沒有整合 | 只是兩個研究放在一起，不是混合方法 |

## 應用前可以自問的問題

1. 哪個研究問題是主軸？回答它需要質性還是量化的證據？
2. 量化部分的樣本數能支持檢定，還是只能描述？
3. 兩種資料在哪一個階段整合？整合的規則是否事先寫定？
4. 如果兩種結果不一致，我打算如何呈現？
