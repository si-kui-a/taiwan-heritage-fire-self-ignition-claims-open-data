# 配對方法（Matching Methods）

建立：2026-09-30｜層次：研究設計｜常用於：觀察研究的因果推論，找不到隨機實驗時建立可比較的對照組

**一句話**：為每個處理單位找到觀察得到的條件相近的對照單位，讓兩組在比較前盡量相似。

## 主要文獻

Stuart（M04，2010）回顧配對方法的發展，提出實務流程：先定義距離，再進行配對，然後檢查平衡，最後才估計效果；並強調配對階段不應看結果變項。

## 常見方法

| 方法 | 做法 | 特點 |
|---|---|---|
| 精確配對 | 條件完全相同才配 | 最清楚，但條件多時很難找到配對 |
| 粗化精確配對 | 把連續變項分組後再精確配對 | 在精確與可行之間折衷 |
| 最近鄰配對 | 依距離（例如馬氏距離）找最接近的對照 | 可設卡尺，距離太遠就不配 |
| 傾向分數配對 | 先估計每個單位被處理的機率，再依機率配對 | 把多個條件濃縮成一個分數 |
| 加權 | 以傾向分數的倒數等作為權重 | 保留全部樣本 |

## 流程

1. **選擇配對變項**：處理前就決定、同時影響處理與結果的變項；不可用處理後才發生的變項。
2. **配對**：選擇方法、是否放回、比例（1:1 或 1:k）、卡尺。
3. **檢查平衡**：比較配對後兩組各變項的標準化平均差（常見門檻：絕對值小於 0.1），不看 p 值。
4. **檢查共同支撐**：處理組中找不到相近對照的單位，說明並排除或另行處理。
5. **估計效果**：平衡達標後才看結果變項。

## 限制

| 限制 | 說明 |
|---|---|
| 只能處理觀察得到的變項 | 未觀察的差異仍可能造成偏誤 |
| 樣本減少 | 找不到配對的單位被排除，推論範圍改變 |
| 小樣本時不穩定 | 配對結果受少數單位影響大 |

## 常見誤用

| 誤用 | 問題 |
|---|---|
| 一邊看結果一邊調整配對 | 等於挑選結果 |
| 以 p 值檢查平衡 | p 值受樣本數影響，不是平衡的好指標 |
| 把處理後的變項放入配對 | 可能把效果本身配掉 |

## 應用前可以自問的問題

1. 哪些處理前的條件同時影響處理與結果？
2. 我的對照池夠大嗎？每個處理單位都找得到相近的對照嗎？
3. 平衡的標準是什麼？是否在看結果前寫定？
4. 有哪些重要但觀察不到的差異？
