# 紀錄連結（Record Linkage）

建立：2026-09-30｜層次：資料整理｜常用於：行政資料整合、人口與戶政資料、把地址或名稱對應到地籍與名冊

**一句話**：判斷兩份資料中的兩筆紀錄是否指同一個對象；沒有共同的唯一編號時，用多個欄位的相似程度計算連結的可信度。

## 主要文獻

Fellegi & Sunter（T01，1969）提出機率式紀錄連結的理論：比較兩筆紀錄的各欄位是否一致，依「真的是同一對象時一致的機率」與「不是同一對象時碰巧一致的機率」計算權重，再以兩個門檻決定連結、待人工確認或不連結。

## 兩種做法

| 做法 | 規則 | 適合 |
|---|---|---|
| 確定性連結 | 指定欄位完全相同才連結 | 有可靠的唯一編號，或欄位品質很好 |
| 機率式連結 | 依各欄位的一致程度加權計分 | 欄位有錯字、格式不一、缺值 |

## 機率式連結的核心概念

| 概念 | 說明 |
|---|---|
| m 機率 | 兩筆確實是同一對象時，某欄位一致的機率（反映資料錯誤率） |
| u 機率 | 兩筆不是同一對象時，某欄位碰巧一致的機率（常見值較容易碰巧一致） |
| 權重 | 欄位一致時加 log(m/u)，不一致時加 log((1−m)/(1−u))；各欄位相加得到總分 |
| 兩個門檻 | 高於上門檻視為連結；低於下門檻視為不連結；中間送人工確認 |
| 區塊（blocking） | 只比較某個欄位相同的配對（例如同一縣市），減少比對數量 |

## 操作步驟

1. **標準化欄位**：統一全形半形、異體字、地址寫法、日期格式。
2. **設定區塊**：避免把全部紀錄兩兩比較。
3. **比較與計分**：每個欄位定義一致的標準（完全相同、相似度門檻）。
4. **決定門檻**：以人工檢查的樣本估計錯誤率後決定。
5. **人工確認**：中間區間逐筆確認，記錄依據。
6. **報告品質**：抽樣估計誤連（不同對象被連在一起）與漏連（同一對象沒連上）。

## 常見問題

| 問題 | 例子 |
|---|---|
| 同名異地 | 不同地方有同名的建物或機構：必須加上地區等欄位一起比對 |
| 名稱變更 | 舊名、新名、俗稱 |
| 分割與合併 | 土地地號分割、合併、重劃後，一筆對多筆 |

## 常見誤用

| 誤用 | 問題 |
|---|---|
| 只用名稱比對 | 同名異地造成誤連 |
| 不報告連結品質 | 後續分析的誤差來源被隱藏 |
| 門檻依結果調整 | 連結標準不一致 |

## 應用前可以自問的問題

1. 兩份資料有哪些共同欄位？品質如何？
2. 同名異地、名稱變更的情況多嗎？
3. 誤連與漏連，哪一種對我的分析傷害較大？
4. 人工確認的依據如何記錄？
