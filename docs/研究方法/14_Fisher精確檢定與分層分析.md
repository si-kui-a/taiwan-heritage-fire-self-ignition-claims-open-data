# Fisher 精確檢定與分層分析（Fisher's Exact Test and Stratified Analysis）

建立：2026-09-30｜層次：統計｜常用於：小樣本的類別資料、醫學與社會科學的 2×2 表

**一句話**：在列聯表的邊際總數固定下，直接計算觀察到的表格及更極端表格出現的機率，不需要大樣本假設；需要控制第三個變項時，分層後以 Mantel–Haenszel 方法合併。

## 2×2 表

|  | 結果有 | 結果無 | 合計 |
|---|---|---|---|
| 條件有 | a | b | a+b |
| 條件無 | c | d | c+d |
| 合計 | a+c | b+d | n |

- **勝算比** = (a × d) ÷ (b × c)；1 表示條件與結果無關。
- 任何一格為 0 時，勝算比為 0 或無限大，需要精確方法或加入修正。

## Fisher 精確檢定

| 項目 | 說明 |
|---|---|
| 虛無假說 | 條件與結果獨立 |
| 原理 | 邊際總數固定時，a 服從超幾何分配；把所有與觀察值同樣或更不可能的表格機率加總，即為 p 值 |
| 何時用 | 任一預期次數小於 5、或總樣本小時；卡方檢定的近似在此時不準 |
| 雙尾的定義 | 常見做法是加總所有機率不大於觀察表格的表格；不同軟體定義略有不同，報告時註明 |

## 分層分析與 Mantel–Haenszel 方法

當第三個變項（例如事件的嚴重程度）同時影響條件與結果時，合併分析會混淆。做法是依第三個變項分層，各層各自一張 2×2 表：

| 步驟 | 內容 |
|---|---|
| 1. 分層列表 | 每層列出 a、b、c、d 與勝算比 |
| 2. 合併勝算比 | Mantel–Haenszel 勝算比 = Σ(aᵢdᵢ/nᵢ) ÷ Σ(bᵢcᵢ/nᵢ) |
| 3. 檢查各層是否一致 | 各層勝算比差異很大時，合併值沒有意義，應分層報告 |
| 4. 精確區間 | 樣本小時使用條件精確方法計算合併勝算比的區間 |

## 常見誤用

| 誤用 | 問題 |
|---|---|
| 小樣本用卡方檢定 | p 值不準 |
| 沒分層就下結論 | 被第三個變項混淆 |
| 分層後每層都做檢定 | 樣本被切得更小，又增加多重比較問題；小樣本時分層結果只列表 |
| 把勝算比說成「機率的倍數」 | 結果常見時，勝算比與相對風險差很多 |

## 應用前可以自問的問題

1. 我的表格有哪些格子的次數很小？
2. 有沒有第三個變項可能同時影響條件與結果？
3. 分層後每層還有足夠的資料嗎？還是只能列表描述？
4. 我用的軟體如何定義雙尾 p 值？
