# 描述統計、效果量與精確信賴區間（Descriptive Statistics, Effect Sizes and Exact Confidence Intervals）

建立：2026-09-30｜層次：統計｜常用於：樣本小、只能描述的研究；任何需要報告結果大小的研究

**一句話**：報告「差多少」與「有多不確定」，而不只是「顯著或不顯著」；樣本小時用精確方法計算區間，不依賴大樣本近似。

## 為什麼不只看 p 值

| 問題 | 說明 |
|---|---|
| 顯著不等於重要 | 樣本很大時，微小差異也會顯著 |
| 不顯著不等於沒有差異 | 樣本小時，大差異也可能不顯著；區間很寬代表資料不足以判斷 |
| p 值不告訴你方向與大小 | 效果量與區間才能 |

## 常見效果量

| 資料 | 效果量 | 解讀 |
|---|---|---|
| 兩組比例 | 比例差、相對風險、勝算比 | 勝算比 1 表示沒有關聯 |
| 兩組平均 | 平均差、標準化平均差 | 標準化後可跨研究比較 |
| 計數或發生率 | 發生率、發生率比 | 單位時間內的事件數 |
| 相關 | 相關係數 | −1 到 1 |

## 精確信賴區間

大樣本近似（例如常態近似）在樣本小或比例接近 0、1 時不準，可能產生小於 0 的下限。精確方法直接由機率分配計算。

| 情境 | 方法 | 說明 |
|---|---|---|
| 卜瓦松計數（事件數 k） | Garwood 區間（M01） | 下限 = χ²(α/2; 2k) ÷ 2，上限 = χ²(1−α/2; 2k+2) ÷ 2；k = 0 時下限為 0 |
| 二項比例（n 中有 x） | Clopper–Pearson 區間 | 以二項分配求上下限，概念與 Garwood 相同 |
| 列聯表的勝算比 | 條件最大概似與精確區間 | 見 [Fisher 精確檢定與分層分析](14_Fisher精確檢定與分層分析.md) |

精確區間通常偏保守（實際涵蓋率不低於名目值），這是為了在小樣本時不高估精確度。

## 報告方式

- 每個結果同時報告件數、比例或效果量，以及 95% 區間。
- 區間很寬時，直接說明資料不足以判斷方向，不寫「有趨勢」。
- 描述性研究不做檢定時，說明原因（例如樣本太小、事先定為描述）。

## 常見誤用

| 誤用 | 問題 |
|---|---|
| 只寫「顯著」或「不顯著」 | 讀者不知道差多少 |
| 小樣本用常態近似區間 | 區間錯誤，可能超出合理範圍 |
| 把不顯著寫成「沒有差異」 | 混淆「沒有證據」與「證據顯示沒有」 |

## 應用前可以自問的問題

1. 我要報告的是比例、發生率還是平均？對應的效果量是什麼？
2. 樣本夠大到可以用近似方法嗎？
3. 區間寬到什麼程度時，我會寫「無法判斷」？
