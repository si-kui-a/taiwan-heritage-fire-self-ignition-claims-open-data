# 研究方法總覽

建立：2026-09-30｜狀態：第一版

這一系列文件以教科書的方式介紹社會科學常用的方法論與研究方法：每份說明一個方法的定義、來源文獻、核心概念、操作步驟、品質判準、常見誤用與適用範圍。內容是通用版本，不針對特定研究；讀完後可以用每份文件最後的「應用前可以自問的問題」，自己判斷方法如何用在手上的研究。

文中以代號引用的文獻（例如 M11、P19）對應 `data/references.csv`，每筆都附原始連結與核對狀態。

## 方法論與研究方法

| 層次 | 回答的問題 | 例子 |
|---|---|---|
| 方法論（methodology） | 知識如何成立：研究對象是什麼、什麼算證據、研究者與研究對象的關係 | 社會建構論、實證取向、混合方法 |
| 研究設計（research design） | 用什麼架構比較、推論 | 個案研究、病例交叉設計、差異中的差異 |
| 資料蒐集與整理 | 資料從哪裡來、如何抽樣與連結 | 文件分析、抽樣、紀錄連結 |
| 分析方法 | 如何從資料得到結論 | 內容分析、框架分析、過程追蹤 |
| 統計推論 | 如何量化不確定性 | 精確檢定、置換檢定、多重比較校正 |

同一個研究通常同時用到好幾層：方法論決定可以問什麼問題，設計決定比較的架構，蒐集與分析方法決定證據的品質。

## 閱讀順序建議

1. 先讀 01、02，理解研究對象與證據的基本立場。
2. 再讀 03、04、17–20，比較不同的研究設計如何建立對照。
3. 分析方法（05–10、22、25）與統計方法（13–16、21、23）依需要查閱。
4. 最後讀 26，任何使用真實個案的研究都適用。
