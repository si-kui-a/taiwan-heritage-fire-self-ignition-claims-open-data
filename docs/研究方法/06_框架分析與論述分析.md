# 框架分析與論述分析（Frame Analysis and Discourse Analysis）

建立：2026-09-30｜層次：分析方法｜常用於：新聞研究、社會運動研究、政策論述研究

**一句話**：分析文本選擇強調現實的哪些面向，以及這些選擇如何引導讀者理解問題、原因、責任與解方。

## 主要文獻

| 文獻 | 貢獻 |
|---|---|
| Entman（M12，1993） | 把框架定義為「選擇與凸顯」：文本凸顯某些面向，從而提出特定的問題定義、因果解釋、道德評價與處理建議 |
| Nijjar（P35，2015） | 以批判論述分析研究英國媒體如何描述特定群體，示範論述分析如何連結文本與權力關係 |

## 框架的四個功能（Entman）

| 功能 | 問題 | 在文本中找什麼 |
|---|---|---|
| 定義問題 | 發生了什麼？問題是什麼？ | 標題、導言、用來命名事件的詞 |
| 診斷原因 | 誰或什麼造成的？ | 被指為原因的行動者或制度 |
| 道德評價 | 好壞對錯如何判斷？ | 形容詞、比喻、引述誰的評價 |
| 建議處理 | 該怎麼辦？ | 呼籲、政策建議、要求負責的對象 |

一篇文本不一定四個功能都有；框架也常由「省略了什麼」構成。

## 框架分析與論述分析的差別

| 面向 | 框架分析 | 批判論述分析 |
|---|---|---|
| 焦點 | 文本如何組織對事件的理解 | 語言如何再生產或挑戰權力關係 |
| 常見做法 | 定義框架類別後編碼、計數 | 細讀少量文本，分析用詞、句法、敘事位置 |
| 與量化結合 | 容易：框架可以當作內容分析的類別 | 較少：重視詮釋深度 |

## 操作步驟

1. **找出候選框架**：從既有文獻與試讀文本，列出可能的框架及其辨識特徵（關鍵詞、比喻、引述對象、因果敘述）。
2. **寫成編碼表**：每個框架附定義、判準與範例；一篇文本可有主要框架與次要框架。
3. **編碼與信度**：同[內容分析](05_內容分析.md)與[編碼信度](07_編碼信度與Krippendorff_alpha.md)。
4. **分析**：框架隨時間、媒體、事件類型的變化；框架與提出者的關係。
5. **論述層次（選用）**：挑選代表性文本細讀，分析用詞與敘事如何建立框架。

## 常見誤用

| 誤用 | 問題 |
|---|---|
| 框架類別只由研究者直覺決定 | 難以重複，也可能只看到預期的框架 |
| 把「關鍵詞出現」等同框架 | 框架是整體的組織方式，單一詞可能出現在不同框架 |
| 把文本框架等同讀者的理解 | 讀者會協商或抵抗框架，需要閱聽人資料才能談效果 |

## 應用前可以自問的問題

1. 我要找的是事先定義的框架，還是從文本歸納框架？
2. 每個框架的辨識特徵是否具體到可以重複判斷？
3. 被省略的面向如何記錄？
4. 需要論述分析的細讀嗎？挑選文本的規則是什麼？
