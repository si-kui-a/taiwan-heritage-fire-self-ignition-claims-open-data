# 抽樣與可重現的隨機化（Sampling and Reproducible Randomization）

建立：2026-09-30｜層次：資料蒐集｜常用於：內容分析、調查研究、信度檢驗的重編樣本

**一句話**：母體太大無法全部分析時，用事先寫定的規則抽出樣本，並固定亂數種子，讓任何人都能抽出同一份樣本。

## 常見抽樣方式

| 方式 | 做法 | 適合 |
|---|---|---|
| 簡單隨機抽樣 | 每個單位被抽中的機率相同 | 母體同質 |
| 分層隨機抽樣 | 先依某個變項分層（例如年份），各層內隨機抽樣 | 各層數量差異大，要確保每層都有代表 |
| 系統抽樣 | 每隔固定間隔抽一個 | 清單順序與研究變項無關時 |
| 立意抽樣 | 依研究目的挑選 | 質性研究、個案選擇；不能做機率推論 |
| 全查 | 不抽樣，全部分析 | 母體小 |

## 分層的配置

| 配置 | 做法 | 取捨 |
|---|---|---|
| 等比例 | 各層依母體比例抽 | 樣本分布與母體一致，可直接估計整體 |
| 不等比例 | 小的層多抽 | 小層也有足夠樣本比較，但估計整體時要加權 |

## 可重現的隨機化

1. **事先寫定**：抽樣規則、各層樣本數、亂數種子，在看到要抽的資料之前寫下。
2. **用程式抽**：以固定種子的亂數產生器抽樣，保存程式與輸入清單。
3. **保存結果**：抽中的單位清單存檔，之後的分析都用同一份。
4. **記錄例外**：抽中但無法取得的單位，記錄原因，不以其他單位任意替補（替補規則也要事先寫定）。

固定種子的目的不是讓結果「剛好」，而是讓別人能驗證抽樣沒有被挑選過。

## 常見誤用

| 誤用 | 問題 |
|---|---|
| 抽完覺得不好再抽一次 | 等於挑選樣本，隨機化失效 |
| 用立意樣本估計母體比例 | 沒有機率基礎 |
| 分層後不等比例抽樣，卻直接合併計算 | 整體估計有偏誤，需要加權 |

## 應用前可以自問的問題

1. 我的母體清單完整嗎？清單本身的收錄偏誤是什麼？
2. 需要分層嗎？依什麼變項？
3. 抽樣規則與種子是否在看資料前寫定並保存？
4. 抽中卻取不到的單位如何處理？
