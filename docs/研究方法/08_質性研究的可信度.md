# 質性研究的可信度（Trustworthiness in Qualitative Research）

建立：2026-09-30｜層次：分析品質｜常用於：訪談、文件分析、個案研究、質性內容分析

**一句話**：質性研究無法只用一個係數證明可靠，而是用一組做法，讓讀者可以檢查結論是怎麼從資料來的、研究者的立場如何影響判斷。

質性方法教科書常以可信度（credibility）、可轉移性（transferability）、可靠性（dependability）、可確認性（confirmability）描述質性研究的品質；下表是對應的常見做法。

## 常見做法

| 做法 | 內容 | 回應的問題 |
|---|---|---|
| 審查軌跡（audit trail） | 保存每個判斷的依據：原始文本、編碼、備忘錄、查證紀錄，讓結論可以一路追回原始資料 | 別人能不能檢查我的推論過程？ |
| 反例分析（negative case analysis） | 主要論點提出後，主動找出不符合的個案或文本，說明它們如何修正或限制結論 | 結論是不是只看了支持的證據？ |
| 反身性（reflexivity） | 研究者在分析前寫下自己對研究對象的預設、立場與利害，分析後回頭對照 | 研究者的立場如何影響判斷？ |
| 三角檢核（triangulation） | 用不同資料來源、方法或理論檢驗同一結論；方法三角檢核例如以詞典計分對照人工編碼 | 結論是否依賴單一來源或方法？ |
| 厚描述（thick description） | 詳細描述脈絡，讓讀者判斷結論能否轉用到其他情境 | 結論適用範圍多大？ |
| 同儕檢閱 | 請不參與研究的人檢視編碼與推論 | 有沒有明顯的盲點？ |
| 備忘錄（memo） | 分析過程中隨時記錄新類別、疑問與決定的理由 | 分析的決定何時、為什麼做出？ |

## 操作步驟

1. **分析前**：寫反身性備忘錄；決定審查軌跡要保存哪些檔案。
2. **分析中**：每個新類別或重要決定都寫備忘錄；編碼與原始資料保持連結。
3. **形成論點後**：做反例分析，並用另一種資料或方法三角檢核。
4. **撰寫時**：說明用了哪些做法、發現了哪些反例、結論因此如何調整。

## 常見誤用

| 誤用 | 問題 |
|---|---|
| 只宣稱「做了三角檢核」但不報告結果 | 讀者無法判斷檢核是否改變結論 |
| 反例放在附註或省略 | 失去反例分析的功能 |
| 反身性只寫研究者背景 | 應寫具體的預設，以及它可能影響哪些判斷 |
| 用質性資料的次數做統計推論 | 質性抽樣通常不是機率抽樣 |

## 應用前可以自問的問題

1. 我的預設是什麼？它最可能影響哪一種判斷？
2. 從結論追回原始資料，需要保存哪些檔案？
3. 我的主要論點，最可能的反例是什麼？
4. 有沒有第二種資料或方法可以檢驗同一結論？
