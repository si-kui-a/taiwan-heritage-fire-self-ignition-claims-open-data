# 特徵價格法（Hedonic Pricing Method）

建立：2026-09-30｜層次：統計模型｜常用於：不動產經濟、環境經濟、文化資產與都市設施的價值評估

**一句話**：把一件商品（例如一塊土地或一棟房子）的價格，看成由它的各項特徵共同決定，用迴歸估計每一項特徵的「隱含價格」。

## 主要文獻

Rosen（M10，1974）建立特徵價格的理論基礎：在差異化商品的市場中，價格函數反映買賣雙方對各項特徵的評價，函數對某特徵的斜率即為該特徵的隱含價格。

## 基本模型

價格 = f（結構特徵、區位特徵、鄰里特徵、時間）+ 誤差

| 特徵類型 | 例子 |
|---|---|
| 結構 | 面積、屋齡、構造、樓層 |
| 區位 | 與市中心、車站的距離 |
| 鄰里 | 學區、公園、噪音、文化資產鄰近與否 |
| 制度 | 使用分區、容積、管制 |
| 時間 | 交易年份（控制整體價格變動） |

常見形式是以價格的對數為依變項，係數可解讀為特徵變動一單位時價格變動的百分比（近似）。

## 價格資料的選擇

| 資料 | 優點 | 限制 |
|---|---|---|
| 實際成交價 | 反映市場 | 交易稀少的地點樣本少；有選擇偏誤（有交易的不一定代表全部） |
| 政府公告的估價（例如公告土地現值） | 每筆土地每年都有，涵蓋完整 | 是行政估價，與市價有落差，且調整可能落後 |
| 估價師估價 | 可涵蓋無交易者 | 取得不易，方法不一 |

## 常見問題

| 問題 | 說明 | 處理 |
|---|---|---|
| 遺漏變項 | 未觀察的區位品質同時影響價格與特徵 | 加入地區固定效果；搭配[差異中的差異](18_差異中的差異與事件研究.md)等設計 |
| 函數形式 | 真實關係未必是線性 | 比較不同形式，或用彈性形式 |
| 空間相關 | 相鄰土地的價格相關 | 空間模型或以地區為群聚計算標準誤 |
| 市場分割 | 不同市場的價格函數不同 | 分區估計 |

## 常見誤用

| 誤用 | 問題 |
|---|---|
| 把隱含價格當作因果效果 | 特徵與未觀察因素相關時，係數不是因果 |
| 把行政估價當成市價 | 兩者落差需要說明 |
| 忽略整體價格變動 | 需要控制時間，或以同期同區的價格標準化 |

## 應用前可以自問的問題

1. 我要估計的是哪一項特徵的價格？它與哪些未觀察因素相關？
2. 價格資料是成交價還是估價？各自的偏誤是什麼？
3. 如何控制整體的價格漲跌？
4. 相鄰單位的相關如何處理？
