# 質性比較分析（Qualitative Comparative Analysis, QCA）

建立：2026-09-30｜層次：分析方法｜常用於：中等數量個案（約 10–50 個）的比較研究，政治學、社會學、組織研究

**一句話**：把每個個案看成一組條件的組合，用集合論與布林邏輯找出哪些條件組合足以導致結果。

## 主要文獻

Ragin（M18）說明模糊集合 QCA（fsQCA）：個案對每個條件的隸屬程度介於 0 到 1，而不只是有或無，並介紹校準、真值表與一致性、涵蓋度等指標。

## 核心概念

| 概念 | 說明 |
|---|---|
| 條件與結果 | 以集合表示，例如「屬於高開發壓力的個案集合」 |
| 校準 | 把原始資料轉成隸屬程度：完全隸屬（1）、交叉點（0.5）、完全不隸屬（0），三個錨點要有理論或實質依據 |
| 真值表 | 列出所有條件組合，以及每種組合的個案與結果 |
| 一致性（consistency） | 具有某組合的個案中，同時具有結果的程度；衡量「充分性」 |
| 涵蓋度（coverage） | 結果中有多少可以由該組合解釋；衡量「重要性」 |
| 布林最小化 | 把真值表簡化成最精簡的條件組合 |

## QCA 的因果觀

| 特性 | 說明 |
|---|---|
| 組合因果 | 條件要一起出現才有效果，而非各自加總 |
| 殊途同歸 | 不同的條件組合都可以導致同樣的結果 |
| 不對稱 | 導致結果出現的條件，與導致結果不出現的條件，不一定相反 |

## 操作步驟

1. 選擇個案與條件（條件數要少，常見建議是個案數明顯多於條件組合數）。
2. 依事先說明的依據校準每個條件與結果。
3. 建立真值表，決定一致性門檻（常見約 0.8）與最低個案數。
4. 布林最小化，得到解。
5. 回到個案檢查解是否合理，並報告一致性與涵蓋度。

## 限制

| 限制 | 說明 |
|---|---|
| 對校準與門檻敏感 | 錨點或門檻改變，解可能不同 |
| 有限多樣性 | 很多條件組合在現實中沒有個案，簡化時需要假設 |
| 不處理時間順序 | 條件出現的先後需要其他方法，例如過程追蹤 |

## 常見誤用

| 誤用 | 問題 |
|---|---|
| 條件太多、個案太少 | 真值表大部分是空的，結果不穩定 |
| 校準沒有依據，只用樣本平均切分 | 集合的意義不清楚 |
| 把解當作迴歸係數解讀 | QCA 說的是充分與必要，不是平均效果 |

## 應用前可以自問的問題

1. 我的個案數與條件數是否適合 QCA？
2. 每個條件的三個錨點有什麼實質依據？
3. 我期待的是組合因果、殊途同歸嗎？還是其他方法更適合？
4. 沒有個案的條件組合如何處理？
