# 事實查核與說法—事實對照（Fact-Checking Claims Against Records）

建立：2026-09-30｜層次：分析方法｜常用於：謠言與都市傳說研究、媒體查核、宣稱分析的脈絡建構論取向

**一句話**：把說法中可以查證的部分拆出來，逐一對照獨立的紀錄，分類為紀錄支持、紀錄部分支持、紀錄不足、紀錄不支持或說法不具體。

## 主要文獻

Best & Horiuchi（P16，1985）研究「萬聖節糖果被陌生人下毒」的說法：他們查證報紙所報導的每一件事件，發現幾乎沒有能確認的案例，並追查被歸因的死亡案例的真正原因。這項研究示範了如何只查證說法所指的事件，就能回答說法是否屬實，同時不必否定人們擔憂的社會意義。

## 核心概念

| 概念 | 說明 |
|---|---|
| 可查證的主張 | 說法中能以紀錄確認或否定的部分：日期、地點、事件是否發生、官方結論 |
| 不可查證的部分 | 動機、意圖、價值判斷；只能描述，不能查核 |
| 獨立來源 | 與說法本身無關的紀錄，例如官方公告、判決、登記資料 |
| 查證分級 | 依證據強度把每個事實分級，例如有官方文件、多家獨立報導、單一來源 |
| 雙重單位 | 同時以「每一則說法」與「每一個被指涉的對象」彙總，避免少數被大量報導的對象主導結論 |

## 對照的分類

| 分類 | 判準 |
|---|---|
| 紀錄支持 | 說法的主要可查證主張都與紀錄相符 |
| 紀錄部分支持 | 部分相符、部分不符或查無紀錄 |
| 紀錄不足 | 查無任何紀錄支持，也查無紀錄否定 |
| 紀錄不支持 | 紀錄明確顯示主張不成立 |
| 說法不具體 | 說法太籠統，沒有可查證的主張 |

分類判準要在查證前寫定，並附依據欄位。分類用「紀錄」當主詞，而不是說「說法是真的／假的」：研究者只報告紀錄與說法是否相符，並寫明紀錄由誰認定；同一套標準適用於所有說法，包括研究者自己傾向相信的那一方（社會問題研究稱為情境建構論的做法）。

## 操作步驟

1. **拆解說法**：把每則說法中的可查證主張逐項列出。
2. **決定查證範圍**：通常只查證說法所指的對象；範圍與上限事先寫定。
3. **找獨立紀錄**：每個主張找最接近原始的紀錄，記錄來源與查證分級。
4. **對照與分類**：依寫定的判準分類，附依據。
5. **一併檢驗對立解釋**：說法不成立時，其他解釋是否較能說明事件。
6. **彙總**：以說法與以對象為單位各做一張表。

## 界線

- 查核的是說法與紀錄的關係，不是判定個人責任；沒有判決的事件，只寫可查證的客觀事實。
- 「查無紀錄」不等於「沒有發生」，「紀錄不足」要與「紀錄不支持」分開。
- 分析說法內容（例如情緒、框架）時，應遮蔽查證結果，避免依結果判斷說法。

## 應用前可以自問的問題

1. 每則說法中，哪些部分可以查證，哪些不行？
2. 我的獨立紀錄從哪裡來？它們本身有什麼偏誤？
3. 分類判準是否在查證前寫定？
4. 如何避免查證結果影響說法內容的編碼？
