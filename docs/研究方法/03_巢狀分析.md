# 巢狀分析（Nested Analysis）

建立：2026-09-30｜層次：研究設計｜常用於：比較政治、比較社會學、需要從很多個案中挑少數深入的研究

**一句話**：先用大樣本分析看整體模式，再依分析結果有系統地挑選個案做深入的小樣本分析，讓兩者互相檢驗。

## 主要文獻

Lieberman（M20，2005）提出巢狀分析，作為比較研究中結合大樣本統計與個案研究的策略，重點是「個案選擇由大樣本分析的結果決定」，而不是由研究者的熟悉程度決定。

## 流程

| 步驟 | 內容 |
|---|---|
| 1. 大樣本分析（LNA） | 以所有可得單位做初步分析，找出整體模式與各單位在模式中的位置 |
| 2. 判斷結果是否穩健 | 模式清楚、符合理論時，進入模型檢驗；不清楚或不符合時，進入模型建構 |
| 3a. 模型檢驗的個案研究 | 挑選符合整體模式的個案，檢查模式背後假設的機制是否真的存在 |
| 3b. 模型建構的個案研究 | 挑選能顯示解釋變項差異、或偏離預測的個案，從中找出被遺漏的因素 |
| 4. 回到大樣本 | 個案研究發現的新因素，若可以測量，回到大樣本再檢驗 |

## 核心概念

| 概念 | 說明 |
|---|---|
| 個案選擇規則 | 挑哪些個案、為什麼挑，要在看個案細節之前寫定，避免只挑支持結論的個案 |
| 符合模式的個案 | 用來確認機制：統計上的關聯是否真的由理論說的過程造成 |
| 偏離的個案 | 用來發現新解釋：為什麼這個個案不符合整體模式 |
| 對比個案 | 條件相近但結果不同的個案，幫助排除共同條件 |

## 優點與限制

| 優點 | 限制 |
|---|---|
| 個案選擇有依據，可以說明為什麼是這幾個 | 大樣本分析的品質決定個案選擇的品質 |
| 統計關聯與因果機制互相補強 | 個案研究耗時，能深入的個案數有限 |
| 偏離個案成為修正理論的線索，不再只是雜訊 | 大樣本與個案的測量方式不同時，結果不容易直接比較 |

## 常見誤用

- 先做熟悉的個案，事後才用大樣本「挑出」它們：選擇規則形同虛設。
- 只挑符合模式的個案，沒有檢查偏離者。
- 大樣本只是描述，卻宣稱個案結果可以推論到整體。

## 應用前可以自問的問題

1. 我的大樣本是什麼？它能提供可靠的整體模式嗎？
2. 個案選擇規則是什麼？是否在看到個案細節前寫定？
3. 我需要模型檢驗、模型建構，還是兩者？
4. 有沒有條件相近但結果不同的對比個案可以選？
