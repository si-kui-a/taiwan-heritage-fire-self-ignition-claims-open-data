# 差異中的差異與事件研究（Difference-in-Differences and Event Studies）

建立：2026-09-30｜層次：研究設計｜常用於：政策評估、都市與土地經濟、任何「某個事件發生後，受影響者是否與其他人不同」的問題

**一句話**：比較處理組在事件前後的變化，減去對照組同期的變化，剩下的差就是事件的效果估計；前提是沒有事件時兩組會平行變化。

| 文獻 | 貢獻 |

| Cameron、Gelbach & Miller（M09，2008） | 群數少時以 wild cluster bootstrap 改善推論 |

## 基本形式

|  | 事件前 | 事件後 | 變化 |
|---|---|---|---|
| 處理組 | A₀ | A₁ | A₁ − A₀ |
| 對照組 | B₀ | B₁ | B₁ − B₀ |
| 差異中的差異 |  |  | (A₁ − A₀) − (B₁ − B₀) |

## 核心假設與檢驗

| 假設 | 說明 | 如何檢查 |
|---|---|---|
| 平行趨勢 | 沒有事件時，兩組的變化相同 | 事件研究圖：事件前各期的差異應接近 0（但通過不代表假設成立） |
| 沒有預期效果 | 事件前，處理組沒有因預期而提前改變 | 檢查事件前是否已出現差異 |
| 沒有外溢 | 對照組不受事件影響 | 選擇不會被影響的對照組 |

## 事件研究

把事件前後每一期（例如 −5 到 +5 年）的處理組與對照組差異分別估計、畫成圖。事件前各期用來檢查趨勢，事件後各期顯示效果如何隨時間變化。

## 近年發現的問題

| 問題 | 說明 | 處理 |
|---|---|---|
| 處理時點不同 | 傳統雙向固定效果迴歸會用「已處理」的單位當對照，效果不同時估計可能有偏 | Callaway & Sant'Anna 等方法，只用尚未或從未處理者當對照 |
| 處理組很少 | 群聚標準誤需要很多群才準確 | Conley & Taber、Ferman & Pinto、wild cluster bootstrap、安慰劑置換 |
| 事前趨勢檢定的檢定力低 | 檢定不顯著不代表沒有趨勢差異 | 報告事前各期估計與區間，討論可容許的偏離 |

## 常見誤用

| 誤用 | 問題 |
|---|---|
| 以事前趨勢「不顯著」證明平行趨勢 | 檢定力可能很低 |
| 處理時點不同仍用傳統迴歸 | 估計可能有偏誤 |
| 處理組只有幾個仍用一般群聚標準誤 | 推論過度樂觀 |

## 應用前可以自問的問題

1. 對照組為什麼能代表處理組「沒有事件時」的變化？
2. 事件前有多少期資料可以檢查趨勢？
3. 處理組有幾個？處理時點是否相同？
4. 有沒有可能事件前就已經有預期效果？
