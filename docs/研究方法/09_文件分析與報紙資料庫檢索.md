# 文件分析與報紙資料庫檢索（Document Analysis and Newspaper Database Research）

建立：2026-09-30｜層次：資料蒐集｜常用於：歷史社會學、政策研究、媒體研究、次級資料研究

**一句話**：把既有文件（報紙、公報、會議紀錄、判決、公告）當作研究資料，並且系統地記錄怎麼找、找到什麼、來源有什麼偏誤。

## 文件的種類

| 種類 | 例子 | 特性 |
|---|---|---|
| 官方文件 | 法規、公告、會議紀錄、審議決議、判決 | 程序與日期可靠；只記錄機關關心的事 |
| 新聞報導 | 報紙、通訊社稿、電子新聞 | 時效性高；受新聞價值與媒體立場影響 |
| 組織文件 | 團體聲明、陳情書、網站文章 | 反映特定立場；保存不完整 |
| 回顧性文件 | 多年後的專題、回憶、懶人包 | 常經過重述與簡化，不能當作事件當時的紀錄 |

## 來源評估

| 問題 | 說明 |
|---|---|
| 誰寫的、為了什麼 | 作者身分與目的影響寫了什麼、沒寫什麼 |
| 何時寫的 | 事件當時與事後回顧要分開 |
| 是否為原始來源 | 轉載、改寫、同一通訊社稿要追回原始版本 |
| 保存與收錄 | 資料庫從哪一年開始收錄、是否漏收某些版面或地方版 |

## 報紙資料庫檢索的步驟

1. **確認資料庫與使用條款**：收錄起訖年份、涵蓋的報紙與版別、是否允許程式讀取（很多商業資料庫只允許人工檢索）。
2. **設計查詢**：列出關鍵詞與變體（同義詞、舊稱、簡稱），寫定布林組合與年份範圍。
3. **記錄每次查詢**：資料庫、查詢式、年份、查詢日期、命中數；之後任何人都能重跑。
4. **去重**：同一篇的不同版次、同一集團的轉載、同一通訊社稿視為同一來源。
5. **篩選**：依事先寫定的納入與排除標準，決定哪些命中文本進入分析；排除的也記錄理由。
6. **保存書目資料**：報紙、日期、標題、版次、連結；全文依著作權規定只作研究使用。

## 常見偏誤與處理

| 偏誤 | 例子 | 處理 |
|---|---|---|
| 收錄偏誤 | 資料庫早年只收錄部分報紙 | 逐年計數只用收錄穩定的資料庫，並註明起始年 |
| 搜尋引擎偏誤 | 網路搜尋結果受排序與時效影響 | 趨勢分析不用搜尋引擎，只用可重跑的資料庫查詢 |
| 報導密度差異 | 大都市的事件較常被報導 | 不直接比較不同地區的報導數 |
| 回顧性重述 | 多年後的文章把事件簡化或誇大 | 以發表日期區分當時報導與回顧 |

## 應用前可以自問的問題

1. 我的資料庫收錄了哪些來源、哪些年份？缺了什麼？
2. 查詢式是否寫定並記錄，別人能否重跑得到相同命中數？
3. 同一篇報導被轉載多次時，我怎麼計算？
4. 使用條款允許我怎麼取得與保存資料？
