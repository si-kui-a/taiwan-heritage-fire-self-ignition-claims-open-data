# 病例交叉設計（Case-Crossover Design）

建立：2026-09-30｜層次：研究設計｜常用於：流行病學（短期暴露與急性事件）、事故研究、其他「事件發生前是否剛好出現某個觸發因素」的問題

**一句話**：只研究發生事件的個案，把每個個案事件前的「危險窗口」與同一個案其他時期的「對照窗口」比較暴露，讓每個個案自己當自己的對照。

## 主要文獻

| 文獻 | 貢獻 |
|---|---|
| Maclure（M14，1991） | 提出病例交叉設計，用於研究短暫暴露是否觸發急性事件 |
| Lewer、Petersen & Maclure（M15，2022） | 回顧設計的適用條件、窗口選擇與常見偏誤，並給出實作建議 |
| Suissa（M19，1995） | 提出 case-time-control 設計，以另一組的暴露時間趨勢校正病例交叉設計 |

## 原理

| 概念 | 說明 |
|---|---|
| 危險窗口 | 事件發生前的一段時間，理論上暴露若會觸發事件，應該落在這段時間 |
| 對照窗口 | 同一個案在其他時期、同樣長度的窗口，代表「平常」的暴露機率 |
| 自我對照 | 個案的固定特徵（位置、類型、長期狀態）在兩種窗口相同，自動被控制 |
| 有資訊的個案 | 只有危險窗口與對照窗口暴露不同的個案提供資訊；兩者相同的個案不影響估計 |

以 1:1 窗口為例，估計的勝算比 = 「危險窗口有暴露、對照窗口沒有」的個案數 ÷ 「對照窗口有暴露、危險窗口沒有」的個案數；多個對照窗口時用條件邏輯斯迴歸或 Mantel–Haenszel 方法。

## 適用條件

| 條件 | 不符合時的問題 |
|---|---|
| 暴露是短暫、會變動的 | 長期不變的暴露在兩種窗口都相同，無法估計 |
| 效果是短期的 | 效果持續很久時，對照窗口也受影響 |
| 暴露沒有長期時間趨勢 | 暴露隨時間增加時，較晚的危險窗口本來就較可能有暴露，造成偏誤；以 case-time-control 或雙向對照窗口處理 |
| 事件不影響之後的暴露 | 對照窗口放在事件之後時要特別注意 |

## 操作步驟

1. **寫定窗口**：危險窗口長度、對照窗口的位置與數量，在看結果前決定。
2. **定義暴露**：以可查證的日期為準（例如公告日），寫定判定規則。
3. **排除重疊**：對照窗口不可與任何事件的危險窗口重疊。
4. **計算**：勝算比與精確 95% 區間；報告有資訊的個案數。
5. **敏感度分析**：改變窗口長度；以 case-time-control 校正時間趨勢。

## 常見誤用

| 誤用 | 問題 |
|---|---|
| 看了結果再調整窗口長度 | 等於挑選結果 |
| 只報告勝算比，不報告有資訊的個案數 | 有資訊的個案很少時，區間極寬 |
| 用於長期、緩慢的暴露 | 違反設計前提 |

## 應用前可以自問的問題

1. 我的暴露是短暫事件嗎？它有沒有長期時間趨勢？
2. 危險窗口應該多長？理由是什麼？
3. 預計有多少個案的兩種窗口暴露不同？
4. 對照窗口放在事件之前還是之後？會不會被事件本身影響？
