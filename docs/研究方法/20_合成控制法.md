# 合成控制法（Synthetic Control Method）

建立：2026-09-30｜層次：研究設計｜常用於：只有一個或少數處理單位（一個國家、一個城市、一個地區）的政策評估

**一句話**：找不到一個夠像的對照單位時，用多個未受處理單位的加權組合，「合成」一個在事件前走勢與處理單位幾乎相同的對照，事件後兩者的差距即為效果估計。

## 主要文獻

Abadie、Diamond & Hainmueller（M07，2010）以美國加州菸草管制為例提出並推廣合成控制法，並以安慰劑檢定進行推論。

## 核心概念

| 概念 | 說明 |
|---|---|
| 捐贈池（donor pool） | 可以用來合成的未處理單位 |
| 權重 | 每個捐贈單位的權重非負、總和為 1，使合成單位在事件前的結果與特徵最接近處理單位 |
| 事件前的配適 | 事件前合成單位與處理單位的差距越小，事件後的比較越可信 |
| 安慰劑檢定 | 把每個捐贈單位假裝成處理單位，重做一次；真正處理單位的效果應比大多數安慰劑極端 |

## 操作步驟

1. **界定處理單位、事件時點與結果變項**。
2. **選擇捐贈池**：排除同期也受類似事件影響、或會被外溢影響的單位。
3. **求權重**：以事件前的結果（與其他特徵）配適。
4. **檢查事件前配適**：配適不好就不適合使用。
5. **比較事件後差距**，並做安慰劑檢定與敏感度分析（例如逐一移除捐贈單位）。

## 優點與限制

| 優點 | 限制 |
|---|---|
| 權重透明，可以看出對照由哪些單位組成 | 需要事件前夠長的資料 |
| 適合只有一個處理單位 | 捐贈池不能有同類事件或外溢 |
| 不需要平行趨勢假設，改以事件前配適支持 | 處理單位極端（例如最高或最低）時，加權組合無法配適 |

## 常見誤用

| 誤用 | 問題 |
|---|---|
| 事件前配適很差仍解讀效果 | 差距可能是原本就不同 |
| 反覆調整捐贈池直到結果顯著 | 等於挑選結果 |
| 不做安慰劑檢定 | 缺少推論依據 |

## 應用前可以自問的問題

1. 我的處理單位有幾個？事件前有幾期資料？
2. 哪些單位可以放進捐贈池？哪些必須排除？
3. 處理單位在捐贈池中是否極端？
4. 安慰劑檢定的分配要如何呈現？
