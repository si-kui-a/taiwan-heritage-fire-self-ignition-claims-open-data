# 編碼信度與 Krippendorff α（Coding Reliability and Krippendorff's Alpha）

建立：2026-09-30｜層次：分析品質｜常用於：內容分析、框架分析、任何需要人工判斷分類的研究

**一句話**：用同樣的編碼表重複編碼，衡量結果一致到什麼程度，一致性不夠的類別不能用來下結論。

## 主要文獻

Krippendorff（M11）說明內容分析的三種信度與 α 係數：α 適用任何數量的編碼者、允許缺值，並可依資料尺度（名目、順序、等距、比率）計算。

## 三種信度

| 類型 | 做法 | 能檢驗什麼 | 不能檢驗什麼 |
|---|---|---|---|
| 穩定性（stability） | 同一編碼者隔一段時間重新編碼 | 編碼者自己前後是否一致 | 編碼者一貫的個人偏誤 |
| 再現性（reproducibility） | 兩位以上編碼者各自獨立編碼 | 編碼表能否讓不同人得到相同結果 | 所有人共有的偏誤 |
| 準確性（accuracy） | 與已知正確答案比較 | 編碼是否符合標準 | 很少有現成標準答案 |

一般認為再現性信度較強；只有一位編碼者時，穩定性信度是可行但較弱的替代，報告時要說明限制。

## α 的概念

α = 1 − 觀察到的不一致 ÷ 隨機情況下預期的不一致

| α | 解讀 |
|---|---|
| 1 | 完全一致 |
| 0 | 一致程度與隨機相同 |
| < 0 | 比隨機還不一致，通常表示編碼表或操作有系統性問題 |

Krippendorff 建議的門檻：α ≥ 0.800 可以採信；0.667 ≤ α < 0.800 只能用於暫時性結論；低於 0.667 不應採用。門檻應在計算前決定。

**與百分比一致的差別**：百分比一致沒有扣除「碰巧相同」的部分；某個值很常見時（例如九成文本都編為「無」），百分比一致會很高，α 卻可能很低。

## 操作步驟

1. **決定信度類型與門檻**：事先寫定。
2. **抽出重編樣本**：以固定亂數種子隨機抽出（常見比例 10%–20%），抽樣前不看第一次結果。
3. **獨立重編**：重編時看不到第一次結果；穩定性信度要隔一段時間（例如兩週以上），降低記憶影響。
4. **計算各類別的 α**：依資料尺度選擇距離函數（名目、順序等）。
5. **處理未達標的類別**：照實報告，不用於推論；不可事後放寬門檻。

## 常見誤用

| 誤用 | 問題 |
|---|---|
| 只報告所有類別的平均 α | 個別類別可能遠低於門檻 |
| 看到結果後才決定門檻 | 門檻失去意義 |
| 樣本中某個值極少出現仍計算 α | 估計不穩定，應註明無法可靠估計 |
| 重編時看得到第一次結果 | 高估一致性 |

## 應用前可以自問的問題

1. 我能找到第二位編碼者嗎？若不能，如何說明穩定性信度的限制？
2. 每個類別的資料尺度是什麼？
3. 重編樣本多大？每個值在樣本中是否出現足夠次數？
4. α 未達標時，替代做法是什麼（刪除類別、合併值、只作描述）？
