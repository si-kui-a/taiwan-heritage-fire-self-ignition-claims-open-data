# 事先寫定分析計畫（Pre-Specified Analysis Plan）

建立：2026-09-30｜層次：研究設計｜常用於：實驗與觀察研究、任何會做統計檢定的研究

**一句話**：在看到結果之前，寫定要檢驗的假說、變項定義、檢定方法與判斷標準；之後新增的分析一律標為探索性。

## 為什麼需要

| 問題 | 說明 |
|---|---|
| 分析的彈性 | 同一份資料可以用許多方式分析；看了結果再選分析，容易選到「顯著」的那一個 |
| 事後提出假說 | 看了結果才說「這就是我原本的假說」，把探索包裝成驗證 |
| 多重比較 | 檢定做得越多，至少一個偶然顯著的機率越高（見[多重比較校正](16_多重比較校正.md)） |

事先登記（preregistration）是把計畫公開存檔並附時間戳記的做法；即使不公開登記，在研究文件中寫定並保留版本紀錄，也能達到相同目的的一部分。

## 驗證性與探索性

| 類型 | 條件 | 報告方式 |
|---|---|---|
| 驗證性 | 假說、變項、方法、α 都在看資料前寫定 | 可以依事先的標準下結論 |
| 探索性 | 事後新增、或看過部分資料後才決定 | 標明為探索性，結果作為下一個研究的假說，不作結論 |

## 計畫要寫定的內容

| 項目 | 例子 |
|---|---|
| 假說 | 方向與比較對象 |
| 變項定義 | 如何測量，判定時點 |
| 樣本 | 納入與排除標準、樣本量或上限、抽樣規則 |
| 分析方法 | 檢定、模型、分層方式 |
| 判斷標準 | α 值、單尾或雙尾、效果量的解讀 |
| 前提不成立時怎麼辦 | 例如信度未達標就不執行該檢定，也不改用其他類別替代 |
| 敏感度分析 | 關鍵假設改變時結果是否穩定 |

## 操作步驟

1. 寫定計畫並保存版本（附日期）。
2. 若在寫定前已看過部分資料，照實揭露看過什麼。
3. 執行分析時完全依計畫；偏離計畫之處逐項記錄理由。
4. 報告時分開呈現驗證性與探索性結果。

## 常見誤用

| 誤用 | 問題 |
|---|---|
| 計畫寫得很模糊 | 仍保留大量分析彈性 |
| 偏離計畫卻不報告 | 讀者無法判斷結果可信度 |
| 把「事先寫定」當成不能做任何探索 | 探索可以做，只要標明 |

## 應用前可以自問的問題

1. 我的研究中，哪一個檢定是驗證性的？其他是描述或探索嗎？
2. 寫定計畫前我已經看過哪些資料？
3. 前提不成立時（樣本不足、信度不足）的處理方式寫好了嗎？
4. 計畫的版本紀錄保存在哪裡？
