# 置換檢定（Permutation Test）

建立：2026-09-30｜層次：統計｜常用於：小樣本、資料不符合常態假設、觀察值不獨立但可以分組的情況

**一句話**：如果虛無假說成立，組別標籤就可以任意交換；把標籤重新排列很多次，看觀察到的差異在所有排列中有多極端。

## 主要文獻

Good（M02）系統比較置換檢定、參數檢定與拔靴法，說明置換檢定在「可交換性」成立時是精確的，並介紹分層置換等變化。

## 原理

| 步驟 | 內容 |
|---|---|
| 1. 選統計量 | 例如兩組平均差、比例差、相關係數 |
| 2. 計算觀察值 | 用真實的組別標籤算出統計量 |
| 3. 重新排列 | 在虛無假說下可交換的單位之間，隨機交換標籤，重算統計量 |
| 4. 重複 | 所有可能排列（精確），或隨機抽 1 萬次以上（蒙地卡羅近似） |
| 5. 算 p 值 | 排列中統計量至少和觀察值一樣極端的比例；蒙地卡羅時常用 (極端次數 + 1) ÷ (排列次數 + 1) |

## 可交換性與分層置換

置換檢定的關鍵假設是：虛無假說成立時，被交換的單位之間可以互換。

| 情況 | 做法 |
|---|---|
| 所有單位獨立 | 在全部單位之間置換 |
| 單位成群（例如同一來源的多篇文本、同一個人的多次測量） | **分層置換**：只在同一群內交換標籤，保留群之間的差異 |
| 時間序列 | 一般置換會破壞時間相關，需要區塊置換等特殊做法 |

## 優點與限制

| 優點 | 限制 |
|---|---|
| 不需要常態等分配假設 | 可交換性不成立時結果錯誤 |
| 小樣本也適用 | 檢定的是「標籤與結果無關」，不是特定參數 |
| 可以用任何統計量 | 大資料或複雜模型時運算量大 |

## 安慰劑置換

政策評估中常見的變化：把「處理」假裝發生在未受處理的單位上，重算效果；真正的效果若落在安慰劑效果的分配中間，就很可能只是雜訊。

## 常見誤用

| 誤用 | 問題 |
|---|---|
| 群內不獨立卻在全部單位間置換 | 高估精確度 |
| 看了結果再選統計量 | 失去事先寫定的意義 |
| 蒙地卡羅次數太少 | p 值不穩定 |

## 應用前可以自問的問題

1. 虛無假說下，哪些單位之間可以交換？
2. 我的資料有沒有群聚結構需要分層置換？
3. 統計量是否事先寫定？
4. 排列次數與亂數種子是否記錄？
