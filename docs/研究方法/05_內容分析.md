# 內容分析（Content Analysis）

建立：2026-09-30｜層次：分析方法｜常用於：傳播研究、媒體研究、政策文件與會議紀錄分析

**一句話**：依事先定義的類別與判準，系統地為大量文本編碼，讓文本的特徵可以計數、比較，並能被他人重複。

## 主要文獻

Krippendorff（M11）的教科書把內容分析定義為「從文本對其使用脈絡做出可重複、有效推論的研究技術」，並系統說明抽樣、單位、編碼、信度與推論。

## 核心概念

| 概念 | 說明 |
|---|---|
| 分析單位 | 一次編碼的對象：一篇報導、一個段落、一則發言 |
| 類別（變項） | 要編碼的特徵，例如提出者類型、情緒強度、是否附出處 |
| 編碼表（codebook） | 每個類別的定義、判準、可選的值，以及正反範例 |
| 演繹編碼 | 類別由理論或既有研究事先決定 |
| 歸納編碼 | 類別從文本中浮現；質性內容分析常兩者並用 |
| 顯性與隱性內容 | 顯性：字面上看得到的（是否提到某個詞）；隱性：需要詮釋的（語氣、立場），信度較難達成 |

## 操作步驟

1. **界定研究問題與文本母體**：哪些文本、哪些來源、哪段期間。
2. **抽樣**：母體太大時依事先固定的規則抽樣（見[抽樣與可重現的隨機化](11_抽樣與可重現的隨機化.md)）。
3. **草擬編碼表**：定義每個類別與判準，附正反範例；以少量文本試編並修改。
4. **凍結編碼表**：正式編碼開始後不再修改；若必須修改，已編碼的文本全部重編。
5. **編碼**：逐則記錄，每個判斷可追回原文。
6. **檢驗信度**：重新編碼部分樣本，計算一致性（見[編碼信度與 Krippendorff α](07_編碼信度與Krippendorff_alpha.md)）。
7. **分析與推論**：次數、趨勢、類別間的關係；推論範圍不超過抽樣所代表的母體。

## 編碼表的寫法

| 欄位 | 內容 |
|---|---|
| 類別名稱 | 簡短、唯一 |
| 定義 | 一句話說明要抓什麼 |
| 判準 | 什麼情況編為哪個值；邊界情況如何判斷 |
| 值 | 互斥且窮盡（加上「無法判斷」） |
| 範例 | 至少一則正例與一則反例 |

## 品質判準

- 類別互斥且窮盡，定義清楚到另一個人可以照著編。
- 信度達標的類別才用於推論，未達標的照實報告。
- 容易受其他資訊影響的判斷（例如情緒），編碼時遮蔽可能造成偏誤的資訊。

## 常見誤用

| 誤用 | 問題 |
|---|---|
| 邊編邊改編碼表，不重編 | 前後標準不一致 |
| 只報告次數，不報告信度 | 無法判斷次數是否可靠 |
| 從媒體內容推論閱聽人的想法 | 內容分析描述文本，閱聽人效果需要其他資料 |

## 應用前可以自問的問題

1. 分析單位是什麼？同一事件的多篇報導如何處理？
2. 哪些類別是顯性、哪些是隱性？隱性類別如何提高一致性？
3. 編碼時需要遮蔽哪些資訊？
4. 文本母體的收錄範圍有什麼限制？
