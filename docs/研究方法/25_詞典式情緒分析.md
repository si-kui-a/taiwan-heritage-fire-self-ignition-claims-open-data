# 詞典式情緒分析（Lexicon-Based Sentiment Analysis）

建立：2026-09-30｜層次：分析方法｜常用於：媒體與社群文本的情緒測量、作為人工編碼的對照

**一句話**：用事先建立、每個詞都有情緒分數的詞典，計算文本的平均情緒；方法透明、可重複，但看不懂語境。

## 主要文獻

Yu 等（T04，2016）建立中文效價—喚起詞典（Chinese Valence-Arousal Words），由多位評分者為中文詞彙在兩個維度上評分，可用來計算中文文本的情緒分數。

## 核心概念

| 概念 | 說明 |
|---|---|
| 類別式情緒 | 把情緒分成離散類型（憤怒、恐懼、悲傷等） |
| 維度式情緒 | 以連續維度描述情緒；最常見的是效價與喚起 |
| 效價（valence） | 正面到負面的程度 |
| 喚起（arousal） | 平靜到激動的程度；憤怒與恐懼都是負面高喚起，悲傷是負面低喚起 |
| 詞典 | 每個詞對應分數；文本分數通常是命中詞的平均 |

## 操作步驟

1. **斷詞**：中文需要先斷詞，斷詞結果影響能否對到詞典。
2. **比對詞典**：記錄每則文本命中多少詞；命中太少的文本分數不可靠。
3. **計算分數**：平均效價、平均喚起；可另計最高分。
4. **處理否定與程度詞**：例如「不」「非常」，可設簡單規則，或說明未處理。
5. **驗證**：抽樣比對人工判斷，報告兩者的一致程度。

## 用途與限制

| 適合 | 不適合 |
|---|---|
| 大量文本的粗略比較 | 判斷單則文本的真正情緒 |
| 作為人工編碼的三角檢核（見[質性研究的可信度](08_質性研究的可信度.md)） | 反諷、嘲諷、引述他人話語 |
| 追蹤情緒隨時間變化 | 專業領域用詞（詞典未收錄或意義不同） |

## 與人工編碼搭配

常見做法是把詞典分數與人工強度編碼比較：兩者排序差距最大的文本，回頭重看並記錄是否更改人工編碼。規則（例如差距最大的 10%）要事先寫定，避免只挑某個方向的差異修改。

## 常見誤用

| 誤用 | 問題 |
|---|---|
| 把詞典分數當成真實情緒 | 詞典只看字面 |
| 不報告命中率 | 命中很少的文本分數沒有意義 |
| 用在與詞典建立語料差異很大的文本 | 詞義與強度可能不同 |

## 應用前可以自問的問題

1. 我的文本語言與詞典建立時的語料相近嗎？
2. 平均每則文本能命中多少詞？
3. 反諷與引述在我的文本中多不多？
4. 詞典分數與人工判斷不一致時，規則是什麼？
