# 社會建構論與宣稱分析（Social Constructionism and Claims-Making Analysis）

建立：2026-09-30｜層次：方法論｜常用於：社會問題研究、媒體研究、謠言與都市傳說研究

**一句話**：不先問「這個問題有多嚴重」，而是問「誰、在什麼時候、用什麼證據與說法，讓某件事被當成需要處理的問題」。

## 起源與主要文獻

| 文獻 | 貢獻 |
|---|---|
| Spector & Kitsuse（P19，1977） | 把社會問題定義為個人或團體針對某種「被宣稱的狀況」提出不滿與要求的活動；研究對象是宣稱活動本身，而不是狀況 |
| Best（P25，1990） | 分析宣稱的修辭：宣稱者如何用例子、數字、命名，讓受眾接受問題的存在與嚴重性 |
| Best & Horiuchi（P16，1985） | 以萬聖節糖果被下毒的都市傳說為例，把報導所指的事件逐一查證，示範如何同時研究說法與事實 |

## 核心概念

| 概念 | 說明 |
|---|---|
| 宣稱（claim） | 對某種狀況提出的主張，通常包含「有問題」「問題是什麼」「該怎麼辦」 |
| 宣稱者（claims-maker） | 提出主張的人或組織：媒體、專家、民意代表、倡議團體、官方 |
| 被宣稱的狀況（putative condition） | 宣稱所指涉的狀況；「被宣稱的」表示研究者不預設它是否存在 |
| 宣稱的結構 | 常見分析方式：依據（grounds，例子、統計）、理由（warrants，為什麼要在意）、結論（conclusions，該做什麼） |
| 命名與典型例子 | 給問題一個名字，並以最戲劇化的案例代表整體 |
| 宣稱的生涯 | 宣稱從提出、被媒體採用、被官方回應到制度化或消退的過程 |

## 兩種立場

| 立場 | 主張 | 研究上的意義 |
|---|---|---|
| 嚴格建構論 | 研究者完全不評斷狀況是否真實，只分析宣稱活動 | 避免研究者自己成為宣稱者，但無法回答「說法是否正確」 |
| 脈絡建構論 | 研究宣稱活動的同時，可以用其他資料評估宣稱與可查證事實的關係 | 可以做說法與事實的對照，但要清楚區分「分析說法」與「查核事實」兩個層次 |

## 操作步驟

1. **界定說法**：寫下要追蹤的說法及其變體（同義詞、縮寫、隱喻），並固定檢索範圍。
2. **蒐集宣稱**：從報紙、議會紀錄、官方文件、網路等來源找出所有提出或轉述說法的文本，記錄來源與日期。
3. **追溯首次出現與擴散**：依發表日期排序，找出最早紀錄、轉述關係與使用頻率的變化。
4. **編碼宣稱的內容**：宣稱者類型、依據、理由、結論、修辭（例如數字、典型例子、道德語言）。
5. **分析脈絡**：說法在什麼事件或制度條件下出現、被誰接受或反駁。
6. **（脈絡建構論）對照事實**：把說法中可查證的部分與紀錄比對，見[事實查核與說法—事實對照](10_事實查核與說法事實對照.md)。

## 品質判準

- 檢索範圍與關鍵詞事先固定並記錄，避免只找支持研究者印象的文本。
- 研究者對說法真假的預設寫下來，分析時回頭檢查（見[質性研究的可信度](08_質性研究的可信度.md)）。
- 不支持研究者預設的說法與事實一樣照實呈現。

## 常見誤用

| 誤用 | 問題 |
|---|---|
| 把「說法是建構的」等同「說法是假的」 | 建構論談的是問題如何被界定，真實的狀況同樣要經過宣稱才會成為社會問題 |
| 研究者在文中替說法背書或駁斥，卻沒有證據 | 研究者變成另一個宣稱者 |
| 只分析最有名的宣稱者 | 忽略轉述者與反對者，擴散過程不完整 |

## 與其他方法的關係

- 宣稱的內容常以[內容分析](05_內容分析.md)與[框架分析](06_框架分析與論述分析.md)編碼。
- 宣稱的形成過程可以用[過程追蹤](04_個案研究與過程追蹤.md)深入個案。
- 謠言理論（Allport & Postman，P23；Shibutani，P24；Fine 等，P26）提供另一個互補角度：說法在正式資訊缺席、事件重要而曖昧時產生。

## 應用前可以自問的問題

1. 我研究的是狀況本身，還是關於狀況的說法？兩者的證據與結論分別是什麼？
2. 我採取嚴格或脈絡建構論？如果要查核事實，如何避免讓查核結果影響說法的編碼？
3. 說法有哪些變體？檢索範圍的起訖與限制是什麼？
4. 誰沒有發聲？資料來源是否只收錄某些宣稱者？
