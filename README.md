# 公開可用研究資料：臺灣文化資產火災與「古蹟自燃」說法

研究主題：「古蹟自燃」說法的建構與事實落差——說法如何出現、流傳，與火災紀錄、身分變動、地價等可查證事實是否相符。範圍是全臺灣，臺中為深度個案（案例火災年份 2001–2026）。

## 立場

- **研究的是說法，不是替說法背書或駁斥。** 本倉庫的資料只描述公開紀錄（火災調查分類、文資身分、公告土地現值、法規與文獻），不認定任何一場火災是人為縱火，也不指稱任何人或機關有責任。
- **每筆資料都附出處。** 參考資料表的每一列都有原始連結，並記錄最近一次核對日期與結果；查不到或無法核對的會寫明，不估計。
- **原因不明就寫原因不明。** 案例表的起火原因採消防機關的分類與確認程度，沒有正式結論的案例不另行推論。

## 內容

| 檔案 | 內容 |
|---|---|
| `data/references.csv` | 173 筆參考資料：法規、地方法規、政府指引、方法、技術、資料集、文獻；每筆有連結、用途、核對狀態與日期，法規另附相關條文摘錄 |
| `data/reference_details.csv` | 有 DOI 的文獻之期刊、卷期、頁碼（取自 Crossref） |
| `exports/taichung_cases.*` | 臺中 17 件文化資產火災案例的去識別化變項：年份、文資層級、損害、起火原因分類、查證分級、產權；只有公有者列出名稱 |
| `exports/district_medians.*` | 臺中各行政區 2010–2026 年公告土地現值中位數（已彙總，無個別地號） |

每個資料集都有四個檔案：CSV（UTF-8）、`_codebook.md`（變項與數值標籤）、`.R`（R 讀檔並套用標籤）、`.sps`（SPSS 語法）。

**讀入**：R 在 `exports/` 執行 `source("taichung_cases.R")`；SPSS 開啟 `taichung_cases.sps` 後全部執行。

**`references.csv` 的核對狀態**：`verified` 表示程式已對原始連結核對標題或條文；`manual` 表示網站擋程式讀取，已由人工以瀏覽器核對；其他狀態表示尚未核對成功。

## 不在這裡的

依研究倫理，下列資料不公開：原始案例表、地號、門牌、所有權人、私有或權屬不明個案的名稱，以及新聞全文（著作權屬各報社）。

## 使用方式

- 本倉庫供檢視與學術引用。資料是研究進行中的版本，會更正與增補；引用時請註明取用日期。
- 請勿用本資料推論特定個人或機關的責任。

## 貢獻

歡迎非研究團隊成員的更正與補充：

| 想做的事 | 方式 |
|---|---|
| 指出錯誤、過時連結或遺漏的來源 | 開 issue，附上可公開查閱的原始連結 |
| 新增參考資料 | 開 pull request，在 `data/references.csv` 加一列；`url` 必須是原始出處，`match` 填原始頁面上能找到的名稱 |
| 更正統計檔 | 開 issue 說明哪一列、哪個變項、依據為何；統計檔由原始資料表產生，會從原始資料修正後重新產生 |

每項貢獻都會先對原始連結核對後再採用，採用時可能調整格式。送出貢獻即表示同意以本倉庫的授權釋出。
